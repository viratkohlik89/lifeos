# 2026-09-17 — NEXUS

## Extreme-critic audit (user request)

User asked, in Hinglish, for a complete honest read: how far along is the project, what more
can be done, and — explicitly — *be an extreme critic* and tell them what to change.

I audited rather than opined. Hard numbers pulled from the frozen file:

- `index.html` — **24,905 lines · 1,154,662 bytes**
- Split: **JS 981,205 B (84%) · CSS 167,363 B (14%) · HTML 6,094 B (0.5%)**
- **22 routes** registered (`Router.register`) — 17 with a `NAV` entry, 5 reached only from
  the palette / header / switcher
- A11y: **185 `aria-label`**, 28 `aria-pressed`, 14 `aria-selected`, 8 `aria-modal`, 6
  `aria-checked` — but **only 1 `aria-live`** (the toast stack)
- **`serviceWorker` 0 · `manifest` 0** → not installable
- **One keyboard shortcut in the entire app**: `Ctrl/Cmd+K`. The only other `e.key` handlers
  are `' '`, `','`, `'Enter'`, `'Escape'`
- **0 sync code** (`cloudSync|syncEngine|remote` → no hits)
- 23 confirm dialogs; 4 surfaces say "cannot be undone" / "no undo"; no Trash system
- Three static gates green on the frozen file: `JS OK html=1154662b js=981188b` · `BALANCED` ·
  `DEAD HOOKS OK` (255 hooks · 409 buttons · 0 orphan · 0 unhooked)

### The finding that matters: `task.recurrence` is inert

I expected to find "recurrence isn't built". It is worse — the field exists, is stored, is
normalized, and is **rendered to the user**, but nothing reads it as behaviour:

| Site | Line | What it does |
|---|---|---|
| `Task.create` | 4247 | `recurrence: fields.recurrence \|\| null` — **stored** |
| `normalizeTask` | 5698 | `recurrence: t.recurrence \|\| null` — **preserved** |
| task detail panel | 23777 | `<span class="p-val t-muted">` — **displayed read-only** |

- **No editor exists** — grep for `data-tk-recur` → nothing. The only way the field gets a value
  is the demo seed. A user cannot set it, and cannot clear it.
- **No rollover exists** — `nextOccur|spawn|rollover|advanceTask|repeatNext` → zero hits. A task
  marked "daily" never comes back tomorrow.
- Real recurrence *does* exist, but only in **Automation** (`Automation._materialise` at 8116,
  `runDueAutomations` at 8174, M35) — and that is **Pro-gated**.

So the same concept is represented twice, and the Free-visible copy is the one that lies. The
detail panel tells a Free user "Recurrence — daily" about a task that will never repeat. This is
the **only** place the app breaks its own "no fake interactions" rule (invariant 5), and because
it is a *displayed promise* rather than a missing feature, it is a trust bug. No gate caught it:
`check_dead_hooks.py` only checks that hooks are *read*, and this field has no hook — it is
straight interpolation. A "field that is stored and displayed but never acted on" is a new
failure class worth a gate eventually.

### Secondary findings

- **No undo / no trash.** 23 confirm dialogs is the only safety net, and 4 surfaces admit the
  delete is final. For journals/notes/finance that is a real data-loss risk. Cheapest real fix:
  soft-delete via `deletedAt` + a Trash view + 30-day prune — then the confirm dialogs can go.
- **Not a PWA.** "Offline" means "no network calls", not "installable". Genuinely awkward given
  the single-file `file://` design (a service worker needs https or localhost) — a real decision,
  not just an omission.
- **981 KB of JS in one `<script>`.** Every route parses on load; deliberate (zero build step),
  but it is the cost of the single-file constraint and should be named rather than hidden.
- **1 `aria-live`.** Route changes and filtered-list updates are not announced. The toast stack
  is the only live region.

### Verdict given to the user

Two numbers, not one: **feature coverage ~80%, ship-readiness ~65%.** The engineering quality is
genuinely high (30 suites / 2,588 checks / 22 invariants / 25 recorded traps is a standard most
commercial apps do not meet) — the gap is not craft, it is the four items above.

Ranked next steps given: **M46 = recurrence made real** (or soft-delete + trash), then PWA, then
the keyboard layer, then a second workspace, then sync last.
